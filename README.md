# Audioguía Ávila GPS - PWA

## Uso rápido
1. Sube esta carpeta a cualquier hosting HTTPS:
   - GitHub Pages
   - Netlify
   - Vercel
   - servidor propio con HTTPS

2. Abre la URL desde Chrome en Android.

3. Pulsa:
   - menú de Chrome
   - Añadir a pantalla de inicio o Instalar app

4. Abre la app instalada y pulsa Iniciar GPS.

## Importante
- El GPS en navegadores exige HTTPS salvo en localhost.
- Android puede pausar el navegador si bloqueas la pantalla.
- La voz usa el motor TTS instalado en Android.
- La música ambiental se genera dentro del navegador con WebAudio.
